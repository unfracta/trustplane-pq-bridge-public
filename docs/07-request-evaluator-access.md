# 07. Request Evaluator Access

TrustPlane PQ Bridge is currently in private evaluator and design-partner mode.

The core product repo remains private. Qualified reviewers can request access to a source-free appliance pack and fuller proof materials.

## Who This Is For

1. Security architecture teams evaluating post-quantum readiness.
2. Platform engineering teams responsible for signing or verification boundaries.
3. Regulated engineering teams that need reviewer-readable evidence.
4. Strategic reviewers evaluating policy-controlled cryptographic migration.

## What To Send

When requesting access, include:

1. Your organisation and role.
2. The signing or verification boundary you want to evaluate.
3. Whether the workflow is classical-only, hybrid migration, or PQ-forward.
4. Whether you need appliance evaluation, architecture review, or design-partner discussion.

## What Evaluators Receive

Approved evaluators can receive:

1. source-free appliance materials
2. proof-pack outputs
3. API contract
4. policy behaviour contract
5. verification evidence examples
6. a scoped design-partner discussion

## Commercial Boundary

Evaluator access does not grant production use, redistribution rights, source-code access, or public reference rights unless agreed separately in writing.
